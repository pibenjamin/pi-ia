## Description
Permettre à un client de rester connecté sur plusieurs appareils et de valider un nouvel
appareil par un code à usage unique. Le code est envoyé par FEAT-091 (envoi de codes à
usage unique, CMP-09). Les jetons s'appuient sur FEAT-021.

## Critères d'acceptation
- Un nouvel appareil est validé par code en moins de 2 minutes.
- Le client voit la liste de ses appareils et peut en révoquer un.
