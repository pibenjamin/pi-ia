## Description
Appliquer un code promotionnel au panier. La remise doit apparaître comme une ligne
distincte sur la facture et être correctement reportée en cas de remboursement.

## Critères d'acceptation
- Un code est utilisable une seule fois par client.
- La facture affiche la remise sur une ligne dédiée.
