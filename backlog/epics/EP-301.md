## Description
Un client réserve le même matériel chaque semaine. Le paiement de chaque occurrence passe
par le prélèvement récurrent FEAT-071 (CMP-07). Les rappels utilisent les modèles de
notification paramétrables FEAT-092.

## Critères d'acceptation
- Une série peut être suspendue sans être annulée.
- Chaque occurrence est payée à J-1.
